# personal

Small personal one-off apps, each in its own subfolder under `apps/`.

## Apps

- [`apps/adventure-planner`](apps/adventure-planner/PROJECT_PLAN.md) — a local-only AL/GA/FL biodiversity & scenic-destination trip planner: pairwise Elo ranking of ~150 places, a map with real driving-time contours, and a stats dashboard. Open `apps/adventure-planner/adventure_planner.html` directly in a browser.
